# # Modern JavaScript Calculator

A responsive calculator built with HTML, CSS, and vanilla JavaScript.

The project supports standard arithmetic, decimal calculations, chained operations, keyboard input, error handling, and a mobile-friendly interface.

## Live Demo

[Open the live calculator]https://app.netlify.com/projects/lightcalculator/overview

## Features

* Addition, subtraction, multiplication, and division
* Decimal calculations
* Chained operations
* Clear and delete controls
* Division-by-zero handling
* Keyboard support
* Responsive mobile layout
* Modern dark interface

## Keyboard Controls

| Key            | Action                    |
| -------------- | ------------------------- |
| `0–9`          | Enter numbers             |
| `.`            | Add a decimal             |
| `+`            | Addition                  |
| `-`            | Subtraction               |
| `*`            | Multiplication            |
| `/`            | Division                  |
| `Enter` or `=` | Calculate                 |
| `Backspace`    | Delete the last character |
| `Escape`       | Clear the calculator      |

## What I Improved

This project began as a basic calculator with separate event listeners for each button.

It was later refactored to include:

* Reusable event handling
* Clearer variable and function names
* Accurate decimal calculations
* Safer operator handling
* Responsive CSS Grid layout
* Keyboard accessibility
* Improved error handling

## Running Locally

Clone the repository:

```bash
git clone https://github.com/abhuraya/Calculator.git
```

Open the project folder:

```bash
cd Calculator
```

Then open `index.html` in your browser.
